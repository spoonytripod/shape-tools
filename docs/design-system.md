# 화면 디자인 규약

상태: 적용 중 · 2026-09-25

## 방향

발표 자료용 도형을 만드는 밝은 작업실을 지향한다. 실제 생성 도형을 홈의 탐색 이미지로 사용하고, 편집 화면에서는 캔버스가 가장 넓은 영역을 차지한다. 장식용 이미지나 자동 재생 애니메이션 대신 도형 자체와 사용자 조작에 집중한다.

## 색상과 글자

공통 토큰은 `src/app/globals.css`에서 관리한다.

| 역할 | 색상 |
| --- | --- |
| 작업 공간 | `#F5F8F9` |
| 패널·아트보드 | `#FFFFFF` |
| 기본 글자 | `#20383B` |
| 주요 버튼·선택 | `#176B61` |
| 선택 배경 | `#E9F2EF` |
| 보조 글자 | `#64767A` |

Geist를 본문과 제목에 공통으로 사용한다. 제목은 넓은 여백과 크기로 위계를 만들고, 입력값은 고정 폭 숫자로 표시한다. 도형의 기본 색상과 생성 계산은 UI 테마와 분리한다.

## 배치와 상호작용

- 데스크톱: 형태 설정, 미리보기·저장, 색상 설정을 3열에 배치한다. 1280×720에서도 저장 버튼까지 처음 화면에 보이도록 높이를 조절한다. 색상이 많으면 색상 패널 안에서 스크롤한다.
- 980px 이하: 설정을 한 열로 모으고 미리보기·저장 영역을 옆에 둔다.
- 760px 이하: 미리보기와 다운로드를 먼저 보여주고 설정을 이어서 배치한다. 아주 좁은 화면에서는 저장 패널을 미리보기 위에 둔다. 가로 스크롤 없이 다섯 비율을 표시한다.
- 팔레트는 실제 색상 견본과 이름을 함께 보여주며, 현재 색상과 일치하는 항목을 표시한다.
- `src/lib/shared/color.ts`의 9개 프리셋(Default, Mono, Ocean, Sunset, Forest, Pastel, Spectrum, Indigo, Corporate)을 세 도구가 공유한다. Pyramid는 Default, Stairs는 Indigo, Circular Arrows는 Spectrum으로 시작해 기존 첫 화면의 색을 유지한다. 비슷한 녹색 계열인 Growth는 Forest와 겹쳐 제외했고, Indigo는 기존 계단 도구의 보라 계열을 이름 붙여 남겼다.
- 9개는 사용 순위가 아니라 발표 자료에서 쓰기 쉬운 중립·단색, 자연 계열, 부드러운 파스텔, 강한 대비를 고르게 담기 위한 선정이다. [Adobe Color의 팔레트 안내](https://color.adobe.com/explore)에서 제시하는 대중적 테마 범주도 참고했다.
- 도형 개수를 바꾸면 선택한 팔레트를 새 개수에 맞춰 다시 보간한다. 개별 색상을 수정하면 현재 색 조합을 기준으로 다시 보간하므로 개수 변경 후에도 직접 만든 조합을 유지할 수 있다.
- 색상 목록 제목 옆 버튼으로 색상 적용 순서를 반전한다. 버튼은 일반/반전 상태를 표시하며, 프리셋 선택과 도형 개수 변경 후에도 현재 순서를 유지한다.
- 미리보기 배경은 투명 체크무늬·흰색·검정색·사용자 색상을 제공한다. 마지막 옵션에서 색상 선택기 또는 6자리 HEX 코드를 입력한다. 배경 선택은 SVG/PNG 출력에 영향을 주지 않는다.
- PNG 생성 중에는 진행 상태를 알리고 중복 실행을 막는다. 실패 시 SVG 다운로드를 안내한다.
- 입력 레이블, 키보드 포커스, 본문 바로가기, 선택 상태를 유지한다. 움직임 줄이기 설정을 존중한다.
