# 프로젝트 목표

상태: 방향 확정 · 로컬 코드 전환 완료

## 목적과 사용자

Asset Tools는 발표 자료와 문서 작성에 필요한 모형·도형을 브라우저에서 조정하고 내려받는 도구다. 직접 그리거나 복잡한 그래픽 편집기를 익히는 시간을 줄이고, 발표와 문서에 바로 쓸 수 있는 결과물을 제공한다.

개인 작업용으로 시작했지만 앞으로는 웹사이트에 접속한 다른 사람도 설치나 가입 없이 사용할 수 있게 한다. 핵심 흐름은 **도형 선택 → 수치·색상 조정 → 미리보기 → SVG/PNG 다운로드 → 문서에 삽입**이다.

## 현재 제공 기능

- 3D 피라미드, 3D 계단, 원형 화살표 생성.
- 항목 수와 도형별 치수 조정, 개별 색상과 팔레트 선택.
- 화면 비율 선택, 투명 배경 SVG/PNG 내보내기.
- 브라우저 내부 생성과 README의 GitHub Pages 데모 링크.

기존 GitHub Pages 데모는 단일 HTML 파일을 제공한다. 새 Next.js 앱은 로컬에서 실행할 수 있으며 아직 공개 배포하지 않았다. 목표 배포처는 Vercel이다.

## 목표와 확인 기준

| 목표 | 확인 기준 |
| --- | --- |
| 유지보수 가능한 구조 | Next.js·TypeScript에서 화면, 스타일, 도형 계산이 분리되고 도형별 모듈을 독립적으로 수정할 수 있다. |
| 기존 품질 유지 | 기존 세 도형의 조작·미리보기·내보내기가 전환 후에도 같은 의도로 동작한다. |
| 실용 도형 확장 | 신규 도형에 사용 사례, 조절 항목, 유효 범위, 출력 예시가 있다. |
| 쉬운 공개 접근 | 공개 URL에서 첫 방문자가 도형 생성과 다운로드를 완료한다. |
| 발표·문서 활용성 | 발표 자료와 문서에 활용할 수 있는 SVG/PNG 결과물의 크기, 투명도, 시각적 품질을 확인한다. |

발표 자료와 문서 전반에 활용하는 것이 목적이며, 특정 발표 프로그램 전용 호환성 검증은 요구사항에 포함하지 않는다.

## 확장 후보와 우선순위

단계·프로세스, 순환 관계, 계층 구조, 비교·연결 도형을 후보로 둔다. 확정된 구현 목록은 아니다. 실제 문서에서의 사용 빈도, 기존 도형으로 대체 가능한지, 조작 난이도, 출력 호환성을 기준으로 선정한다.

우선순위는 기존 기능 보존과 구조 전환 → 공개 사용성 개선 → 신규 도형 추가 순서다. 로그인, 서버 저장, 협업 편집, 범용 디자인 편집기는 초기 전환 범위에 포함하지 않는다.
